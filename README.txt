ЧТО ДОБАВЛЕНО
1. Десять отдельных архивов по времени:
   02:40, 04:40, 06:40, 07:40, 09:40,
   11:40, 13:40, 16:25, 21:25, 22:40.

2. Разница считается только между соседними тиражами одного времени по дням:
   предыдущая комбинация + разница = текущая комбинация,
   три независимых поля 0–9, модуль 10.

3. В каждом временном архиве четыре режима:
   - Обычный архив
   - Обычный архив + разница
   - Зеркальный архив
   - Зеркальный архив + разница

4. Карточка раскрывается и показывает полное равенство перехода.
   При пропуске дня выводится интервал между тиражами.

5. Поиск исправлен и работает внутри выбранного времени либо по всем 10 временам:
   +106 — точная разница
   106 — точная комбинация
   №267106 — точный номер тиража

6. Добавлен отдельный раздел «ИИ».
   Для каждого времени строится своя модель только по его дневной цепочке.
   Модель показывает основную цифру и два резерва для каждого из трёх полей,
   зеркальный переход и честную проверку без подглядывания в будущее.

ВАЖНО
ИИ-блок является аналитическим экспериментом и не гарантирует результат.
Слабый сигнал означает отсутствие подтверждённого преимущества модели.
