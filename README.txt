Yulia TOP-3 v1.0.13 — Позитроны, зеркальный архив и ИИ

Добавлено:
1. Обычный архив.
2. Обычный архив + разница Позитронов.
3. Зеркальный архив.
4. Зеркальный архив + зеркальная разница.
5. Поиск по номеру, дате, обычной/зеркальной комбинации и разнице.
6. Экспериментальная ИИ-модель следующего перехода по трём независимым полям модуля 10.
7. Основной переход, три кандидата на каждое поле, расчётная следующая комбинация и честный последовательный бэктест без подглядывания.

Правило Позитронов:
каждое из трёх полей считается отдельно в диапазоне 0–9;
Δ = (новая цифра - предыдущая цифра + 10) mod 10.
Зеркало: z(x) = (10 - x) mod 10.
